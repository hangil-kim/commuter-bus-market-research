## 🔴 핵심 결론

### 1. 공공 통근버스 시장은 4중 구조적 장벽으로 시스템 단독 사업자(모빌리전트 포함)의 진입을 원천 차단한다

| 장벽 | 근거 법령/제도 |
|------|---------------|
| ① 전세버스 운송사업 등록 | 「여객자동차운수사업법」 제4조 (업종코드 5805) |
| ② 직접생산확인증명서 | 중소기업제품 구매촉진법 제9조, 공공기관통근운송서비스 코드 7811189901 (중기부 고시 제2024-100호) |
| ③ 자기명의 등록 차량 + 45인승 이상 운행실적 | 공고 명시 |
| ④ **공동계약(컨소시엄) 불허 + 하도급 금지** | 공고 명시 — 시스템사+운수사 컨소시엄 가설 폐기 |

→ 모빌리전트가 시스템만 가진 상태에서는 공공 차량+시스템 번들 시장 진입이 구조적으로 불가능. 진입하려면 **전세버스 자회사 신설 또는 운수사 인수 또는 그룹사 면허 활용**이 필요.

### 2. 시스템사 시장은 "순수 SaaS 3사 + 하이브리드 1사" 구조. 위즈돔은 시스템사가 아닌 하이브리드 사업자

- **헬로버스(CIEL)** [순수 SaaS + 번들 위탁운영]: 354사 (삼성전자·현대차·쿠팡·POSCO·LG화학·SK네트웍스·CJ·한화·농심·현대백화점·넥센·현대모비스 등)
- **위즈돔(Wizdome)** ⭐ **SaaS + 중개 하이브리드 (모빌리전트 직접 경쟁사)** — 7차 확정:
  - **자체 운수면허 없음** — 약 2만개 전세버스 BP 공급망 + 코모빌리티협동조합 기반 중개
  - **2013년 국내 1호 한정면허 취득** (여객자동차운수사업법 시행규칙 제17조) — 일부 노선만 직접 운영 (코모빌리티 사업·경기프리미엄버스)
  - **2개 핵심 제품 라인**:
    - **AIBOS** — SaaS 기반 진보된 관제 시스템
    - **COMMUTE** — B2B 통근솔루션 (좌석예약·차량관제·요금결제·컨텍센터 4대 기능 통합)
  - **카카오모빌리티와 2018.6.20 전략 MOU** (카카오: 빅데이터·AI·노선설계·카카오T 연계 / 위즈돔: AIBOS·운수업·전국 네트워크)
  - 176개 기업 (SK·CJ·한화·카카오·SK하이닉스·HD현대·한국타이어·세메스·서울아산병원·삼성바이오·CJ ENM)
  - **기업별 화이트라벨 앱 배포**: `kr.co.wizdome.commute.{기업명}` (hanwha, amc, samsung.biologics) / `kr.co.wizdome.{기업명}` (cjenm, cheonan, hankooknco)
  - 채용공고에서 CS상담·차량관제·VOC 운영 인력 확인 — 단순 SaaS가 아닌 운영까지 책임지는 모델
- **UNIBUS(썬더디에스)** [순수 SaaS]: 통근·통학·셔틀 3세그먼트. 한경대·목원대·서원대·대덕전자 + KICOX(kicox.unibus.kr 서브도메인 운영). 결제 모듈(신용카드·가상계좌·휴대폰 소액결제) 통합
- **셔틀아이디** [순수 SaaS]: 기업통근·산단셔틀·전세버스 타깃, Freemium SaaS. 구체 고객사 미확인
- **카카오모빌리티 통근셔틀**: **2024년 5월 B2B 시장 철수** (2021 출시 후 3년만). 잔존 고객·리브랜딩 여부 미확인
- **HMG autobus**: HMG 계열사 30~50개 자체 운영 (외부 잠재고객 아님)

→ **위즈돔도 AIBOS SaaS 제공이라 모빌리전트의 직접 경쟁사임** (사용자 지적 정정). 다만 위즈돔은 SaaS + 한정면허 공급중개 + 카카오 제휴까지 묶은 확장 모델로, 단순 SaaS 비교 외에 "운수 중개망"이라는 추가 강점을 가짐. 모빌리전트가 위즈돔과 경쟁할 때는 (1) SaaS 사양·가격 vs (2) 위즈돔의 운수 중개망까지 모두 대응 전략 필요

### 3. 발주 표준 채널 = **서울특별시전세버스운송사업조합 EDM 공문** (공공·민간 공통)

6차 조사로 패턴이 **공공·민간 모두에서 표준임이 확정**:
- **민간**: LG디스플레이 파주 3건 (2023.02.23, 2023.07.05, 2023.07.26 — 1년 내 동일 채널 반복) + 셀트리온 (2023.09)
- **공공**: 국회사무처 (2022.12.22), 정부서울청사 (2023.10.31) — 공공기관도 나라장터 공고 + 조합 EDM 채널 병행

**공통 패턴**: 발주처 → 서울특별시전세버스운송사업조합(필요 시 경기도 조합 동시) → 전회원사 EDM → tourbus.or.kr 첨부 → 본사 담당자 직접 메일 회신

**LG디스플레이 4건 + 셀트리온 + 공공 2건 = 총 7건 1차 자료 면밀 분석 결과**:
- **공고 대상자**: 전세버스 운수사만 (여객자동차운송사업 업종코드 5805 등록 + 자차 70% 이상 + 신용 B- 이상). 시스템사 단독 응모는 **구조적으로 불가능** (10대 미만 권역·셔틀은 100% 자차)
- **운행관리시스템 사양**: LG디스플레이 공고문 모두 시스템·단말기·앱·관제·RFID 명시 **0건**. 셀트리온은 사양서 원문 미확보
- **발주 주체**: LG디스플레이 본사 Global GP팀(김남중 책임 직접 회신) — 조합은 단순 EDM 채널
- **평가 기준**: 종합평가(품질 60% + 가격 40%)
- **계약 구조**: 3년 또는 3년+2년(상호 합의 시 연장)

→ 모빌리전트 영업은 **2-track 전략 필요**: (1) 낙찰 전세버스 운수사와의 사후 시스템 번들 영업 + (2) 발주처(LG디스플레이 GP팀 등) 본사 차원의 시스템 RFP 별도 트랙 공략 + (3) **모빌리전트 그룹사가 전세버스 면허 보유 시 운수사 자격으로 직접 응모**

### 4. 공공 시장은 2026년 상반기 급격히 축소 중 + 민간 단일 사업장이 공공 전체보다 큼

국토부 지시(2026.1.26)로 **혁신도시 이전 공공기관 47개가 2026.3~6월 통근버스 운행 중단** (연 220.49억원 소멸). 반면 단일 민간 사업장만으로도 공공 전체 차량 규모 초과:
- **LG디스플레이 파주: 9권역 224대** (2023년 발주 1차 자료)
- **포스코 포항: 70대 / 연 100만명** (광양 합산 시 100대+)
- 삼성전자 DS 5캠퍼스: 정확한 현 시점 운영 규모 미확인 (과거 인용 수치는 2012년 자료라 제외)
- KICOX: 산단별 다수

→ **모빌리전트 영업의 무게중심은 공공이 아닌 민간**.

## 3. 발주 채널·시스템 조달 메커니즘

### 공공 발주 (나라장터 게시)
```
[공공 발주처]
    ↓ (차량+기사+운영 번들 임차/위탁용역)
[전세버스 운수사 — 면허·직접생산확인 보유]  ← 시스템사 단독 또는 컨소시엄 진입 모두 불가
    ↓ 시스템 조달 (3가지 경로)
    ├── (a) 자체 개발/내부 보유 시스템 (비중 추정 다수)
    ├── (b) 시스템사 OEM/하청 공급 (모빌리전트의 잠재 진입점)
    └── (c) 시스템 미사용, 수기 운영 (정부서울청사 17개사 사례)
```

### 민간 발주 (전세버스조합 회원사 모집 경로 — LG디스플레이 사례)
```
[발주 기업 (예: LG디스플레이 Global GP팀)]
    ↓ 운행사 선정 요건 공문
[서울특별시전세버스운송사업조합]
    ↓ 전회원사 발송 (회신 마감 약 1~2주)
[조합 회원사 전세버스 사업자들]
    ↓ 응모·선정
[낙찰 운수사 (3+2년 계약 등)]
    ↓ 시스템 조달 (위 3경로와 동일)
```

**모빌리전트 진입 채널**:
- (1) **발주 기업 HR/총무팀 직접 영업** (시스템 사양에 영향력 확보)
- (2) **서울시·인천·부산·울산·경북 전세버스조합 회원사 채널 영업** ⭐ 신규 — 낙찰 운수사 대상 OEM
- (3) 발주처가 시스템 사양 미명시 시: 운수사가 시스템 도입 동기 없음 → 진입 불가
