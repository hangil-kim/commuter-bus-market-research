### 2. 시스템사(헬로버스·UNIBUS·셔틀아이디)의 주력 모델은 민간 B2B SaaS 직접 계약 — "가설 1" 확정

- 셔틀아이디는 Lite/Standard/Enterprise 단계별 freemium SaaS (1계정 200명 영구 무료, App Store 직접 다운로드)
- 헬로버스(CIEL)는 차량 운행+노선 관리+관제 시스템을 묶은 **번들형 위탁운영**까지 제공 — 단순 SaaS가 아니라 **운수까지 묶은 통합 위탁 사업자** (CIEL 공식 블로그 명시)
- UNIBUS는 한경대·목원대·서원대·대덕전자 등 직접 운영, **한국산업단지공단 통근버스시스템(2020.07.01 서비스 개시)으로 공공 시스템 단독 분리발주 사례 보유** ← 모빌리전트의 가장 직접적 벤치마크

### 3. 공공 시장 자체가 2026년 상반기 급격히 축소 중

- 국토부 지시(2026.1.26)로 **혁신도시 이전 공공기관 149개 중 47개 → 45개 기관이 2026.3~6월 통근버스 운행 중단** (연 220.49억원 예산 소멸)

## 3. 차량+시스템 번들 공고의 시스템 조달 메커니즘 (추정 다이어그램)

```
[공공 발주처]
    ↓ (차량+기사+운영 번들 임차/위탁용역)
[전세버스 운수사 — 면허·직접생산확인 보유]  ← 시스템사 단독 또는 컨소시엄 진입 모두 불가
    ↓ 시스템 조달 (3가지 경로)
    ├── (a) 자체 개발/내부 보유 시스템 (비중 추정 다수)
    ├── (b) 시스템사 OEM/하청 공급 (비중 미확인)
    └── (c) 시스템 미사용, 수기 운영 (정부서울청사 17개사 사례)
```

→ **모빌리전트의 (b) 진입 가능성**: 운수사에 시스템을 OEM 공급. 단 운수사가 시스템 사양 요구를 직접 받지 않는 한 동기 부족. LH 공고처럼 사양에 "시스템 탑재" 요구가 명시될 때만 외주 수요 발생.

## 5. 영업 타깃 — 누구에게, 어떻게 (2차 보강)

### 우선순위 1: 광역지자체 본·분청사 시스템 단독 분리발주
- **누구**: 17개 시도청 자산관리과/총무과 차량지원팀
- **메시지**: "경기도 모델" 레퍼런스
- **검증 필요**: 17개 중 다른 지자체에 분리발주 선례 추가 존재 여부 (현재 1건만 확인됨 → 모델 확산 가능성 미검증)
- **채널**: 나라장터 알리미 + 직접 방문 영업

### 우선순위 2: 산업단지관리공단·국가산단 관리법인 ⭐ 신규 부상
- **누구**: 한국산업단지공단(KICOX) 본부 + 산단 입주기업 협의체 (군산·시화·반월·창원·울산·여수·구미·온산 등)
- **근거**: UNIBUS가 KICOX와 2020.07.01부터 통근버스시스템 운영. 산단 공동통근버스 제도(2011 시행령 개정, 2015년 말 46개 산단 운행허용)로 시장 존재 확인
- **메시지**: UNIBUS 대체/보완 솔루션, 산단별 RFID+앱+웹 분리발주
- **진입 포인트**: KICOX 본부 또는 산단별 경영자협의회 직접 영업

### 우선순위 3: 민간 대기업·중견기업 B2B SaaS
- **누구**: 헬로버스 354사 외 화이트스페이스 (중견 대기업, 중견 제조사, 신규 산단 입주기업)
- **메시지**: 셔클 운영 노하우 + RFID 직접 개발 가격경쟁력
- **차별화**: 헬로버스 번들 위탁운영과 차별화하려면 "시스템 only + 운수사 자율선택" 포지션 명확화

### 우선순위 4: 대학·병원·종교기관·리조트
- **누구**: UNIBUS·CIEL 미도입 대학, 대형병원, 리조트 (한화 리조트 등)
- **진입 포인트**: 캠퍼스 셔틀 + 직원 통근 통합 솔루션 PoC

### ❌ 제외 타깃 — 지방이전 공기업 본사 (시장 소멸)
- 1차 보고서에서 우선순위 4였으나, 2026.6월까지 47개 → 2개로 축소

## 11-5. 의문 5: 모빌리전트 전세버스 자회사 신설 시 진입비용·기간

**결론** (high, 단 부분 규명): **직접생산확인증명서 절차는 표준화 확인** — 중기부 판로정책과 소관, 4단계 (공공구매종합정보망 SMPP 접속 → 온라인 자료제출·신청서 → 한국중소벤처기업유통원 방문 실사 → 직접생산기업 확인서 발급). SMPP에 973개 품목 기준(중기부 고시 제2024-100호) 등재, 공공기관통근운송서비스(7811189901) 포함. 단 **전세버스 등록 절차·자본금·차고지 요건 + 운수사 인수 가격대는 미규명** (블로그 추정치 5~7주는 0-3 기각).

- **근거**: [중소벤처24 절차 안내](https://www.smes.go.kr/main/pageApplyCertificateDirProd), [SMPP 직접생산확인기준](https://www.smpp.go.kr/dpc/dpCnfirmCrtr/SelectDpCnfirmStdrInfoListVw.do). 법적 근거: 중소기업제품 구매촉진 및 판로지원에 관한 법률 제9조.
- **선행 요건**: 직접생산확인 신청 전에 **(1) SMPP 회원가입 + 기업·공장·제품 정보 등록 → (2) 전세버스 면허 → (3) 직영차량 보유**가 모두 충족되어야 신청 가능.
- **Implication**: 진입 경로 3가지 — (a) 신규 전세버스 자회사 설립, (b) 기존 운수사 인수 (50대 규모 가격대 미규명), (c) **노바/카모마일(KD) 등 그룹사 면허 활용 우회**. 각 옵션 정량 비교는 후속 조사 필요. **(c)가 시간·비용 최소 후보**.
