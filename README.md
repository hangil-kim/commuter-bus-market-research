# 통근버스 운행관리시스템 시장 전수조사 및 모빌리전트 사업 전략 보고서

> **목적**: 한국 통근버스 운행관리시스템 시장 구조 규명 + 모빌리전트(시스템 제품명: 카모마일) 사업 수주 전략 정리
> **마지막 갱신**: 2026-06-15
> **표본**: 공공 공고 14건 + LH 5년치 45건 + 민간 도입 사례 13건 + 시스템사 9사 + 발주 채널 14개 + 운수사 풀(A 9사 / B 13사) — 17회 누적 조사

---

## 📌 경영진 요약 (Executive Summary)

### 1. 시장 진단
- 공공 통근버스 발주 **90%+는 차량/기사 운행용역** (시스템 필수 X) — 모빌리전트는 4중 진입 장벽으로 직접 입찰 구조적 불가
- 시스템 단독 분리발주는 **매우 희소** (광역지자체 3건·대학 1건만 검증) — 경기도청 본청·경기도교육청·서울특별시 초등 스쿨버스·국립목포대
- 민간 시장 규모는 위즈돔(176사)·씨엘모빌리티(354사)가 압도

### 2. 경쟁 구도
- **시스템 단독 분리발주 시장 주요 사업자**: 에스원·유모스원·UNIBUS (경기도청·경기도교육청·서울시·목포대 분점)
- **민간 시장 1·2위**: 위즈돔·씨엘모빌리티 — BPO 일체형(시스템+운수+CS 통합)으로 발주처 락인 강함
- **유모스원 = 42dot 자회사** (현대차그룹) — 공공 분리발주 단가 약 4.5만원/대/월로 직접 경쟁자
- **셔틀아이디 = 디스럽션 위협** — Freemium 200명 무료 + 단말기 불필요(스마트폰·얼굴인식만)

### 3. 모빌리전트 사업 추진 방향
- **2-Track 동시 추진**:
  - (1) 공공 시스템 단독 분리발주 직접 입찰 — 자동 채널 모니터링으로 발주 누락 방지
  - (2) 운수사 OEM 영업 — 위즈돔·씨엘 BPO(Business Process Outsourcing, 업무프로세스 통합 외주) 락인 우회, 낙찰 운수사에 SaaS만 분리 판매
- **풀스택 진입 옵션**: (주)대원관광 카모마일 도입 협상 완결 → SK하이닉스 입찰 대응 + 위즈돔·씨엘과 동급 BPO 경쟁권 진입 가능

### 4. 시스템 구축 (모빌리전트 납품 범위)
- 승하차 인증 단말 (RFID/QR/얼굴인식, 15~30만원/대)
- GPS + LTE 통신 단말 (10~20만원/대)
- SaaS (관제·예약·운영 통합)

### 5. 가격·영업 전략
- **권장 단가**: 차량당 월 **5~7만원** (단말기 포함 풀패키지) — UNIBUS·유모스원 동급, 위즈돔·씨엘 BPO보다 분리 가격 명확화
- **단말기 모델**: 운수사 초기 부담 최소화를 위해 **무상+36개월 약정 위약금(B)** 또는 **임대료 분리(C)** 권장. 매입형(A)은 영업 진입 어려움
- **타겟 운수사**: 검증된 수주 운수사 (활기찬중부관광·스마일관광·수도관광·온버스·리더스투어 등) 우선 + 위즈돔·씨엘 미계약 중견 운수사

### 6. 향후 3개월 최우선 액션 (Top 5)
1. 공고 채널 통합 자동 모니터링 스크립트 구축 (14개 채널 일 1회 자동 + 알림)
2. KD 카모마일 도입 협상 완결 + SK하이닉스 입찰 응모 준비 (위즈돔 HAPPYROAD 정면 경쟁)
3. **공공 시스템 분리발주 입찰 세부 분석 및 차기 입찰 대비** — 경기도청 에스원 낙찰 사양·금액 분석, 광역시 평생교육·교통 부서 정책영업, 시도교육청 차세대 SI 입찰 대비
4. **시스템 사양 명시 운행용역 발주처/계약업체 추적** — 분당서울대병원 2026.5.20 결과, LH 서울본부 차기 공고 시제품, 셀트리온 평가조건 대응
5. 민간 대기업 시스템 도입 의향 영업 타진 (위즈돔·씨엘·UNIBUS 자가신고 명단 외 영역 — 정유석화·식품·중견 제조)

### 핵심 메시지
> 시스템 단독 분리발주는 희소하므로 **공공 직접 입찰만으로는 사업 규모 한계**. **운수사 OEM 영업 + KD 운수업 결합 풀스택 진입**의 2-Track 병행이 필수. 자동 모니터링·KD 협상 완결·POSCO·SK하이닉스 등 핵심 영업 대상의 우선 진입이 향후 3개월 핵심 성과 지표.

# 1부. 시장 구조 분석

## 1-1. 시장의 양분 구조

한국 통근버스 공공 발주는 **2가지 유형**으로 명확히 양분된다:

| 유형 | 정의 | 비중 | 모빌리전트 진입 |
|------|------|------|----------------|
| **① 시스템 단독 분리발주** | 운행관리시스템(단말기·앱·웹) 운영/임차용역만 별도 발주 | 매우 희소 (검증 3건: 경기도청 본청·경기도교육청 북부청사·서울특별시 초등학교 스쿨버스) | ✅ 직접 입찰 가능 |
| **② 차량/기사 운행용역 (시스템 필수 아님)** | 차량·기사·운영 발주 — 시스템 사양은 운수사 자율 (필요시 평가 가점 항목으로 포함) | 공공 발주의 90%+ | ❌ 시스템사 단독 불가 (전세버스 면허 필수) |

**검증된 시스템 단독 분리발주처 (3건, 광역지자체)**:
- 경기도청 본청 — 통근버스 운영용역 (제2026-454/493/517호, 추정 0.89억/36개월/55대) — **에스원 0528 3차 낙찰 완료**
- 경기도교육청 북부청사 — 통근버스 운행관리시스템 임차용역 (R25TA01292759-00, **2025.12.30 수의계약 1,421만원/1년**, 유모스원 단독 수주)
- 서울특별시 — 초등학교 스쿨버스 차량운행관리시스템 운영 용역 (R26TA01516190-00, **2026.2.28 수의계약 1,940만원/1년**, (주)썬더디에스(UNIBUS) 단독 수주) — 광역시도청 본청·광역시도교육청 카테고리 검증 사례 추가

**민간 발주**: 거의 대부분 ② 유형이며 시스템 사양 명시 없음 → 시스템 도입 결정은 운수사 자율 또는 발주처 본사 GP팀 별도 RFP

## 1-2. 4중 진입 장벽 (공공 시장)

| 장벽 | 근거 법령/제도 |
|------|--------------|
| ① 전세버스 운송사업 등록 | 「여객자동차운수사업법」 제4조 (업종코드 5805) |
| ② 직접생산확인증명서 | 중소기업제품 구매촉진법 제9조 (공공기관통근운송서비스 코드 7811189901, 중기부 고시 제2024-100호) |
| ③ 자기명의 등록 차량 + 45인승 이상 운행실적 | 공고 명시 |
| ④ **공동계약(컨소시엄) 불허 + 하도급 금지** | 공고 명시 — 시스템사+운수사 컨소시엄 가설 봉쇄 |

→ **모빌리전트가 시스템만 가진 상태로 공공 차량+시스템 번들 시장 진입은 구조적으로 불가능.** 진입하려면 (a) 그룹사 면허 활용, (b) 전세버스 자회사 신설, (c) 기존 운수사 인수 중 선택.

## 1-3. 발주 채널 구조

### 공공 채널
```
[발주처]
    ↓
[나라장터(g2b.go.kr) 또는 LH e-bid(ebid.lh.or.kr) 또는 자체 게시판]
    ↓
[전세버스 운수사 응모 — 4중 장벽 충족 필수]
    ↓ 낙찰 후 시스템 조달 (3가지 경로)
    ├── (a) 운수사 자체 보유 시스템 (다수)
    ├── (b) 시스템사 OEM 공급 (← 모빌리전트 진입점)
    └── (c) 시스템 미사용 수기 운영 (정부서울청사 17개사 사례)
```

### 민간 채널 — 서울특별시전세버스운송사업조합 EDM
```
[발주 기업 본사 GP팀]
    ↓ 운행사 선정 공문
[서울특별시전세버스운송사업조합(+경기도 조합 동시)]
    ↓ 전회원사 일괄 EDM 발송
[조합 회원사 응모 — 자차 70% + 신용 B- 이상]
    ↓
[OT설명회 → 본사 직접 평가(품질 60% + 가격 40%)]
    ↓ 낙찰 (3년 또는 3+2년 계약)
[낙찰 운수사 — 시스템은 운수사 자율 또는 본사 별도 RFP]
```

**공통 채널 확정 사례 (조합 EDM 통과)**:
- 민간: LG디스플레이 4건(2023.02·07.05·07.26 외), 셀트리온(2023.09.11)
- 공공: 국회사무처(2022.12.22), 정부서울청사(2023.10.31)

**핵심 시사점**: tourbus.or.kr 모니터링이 모빌리전트의 민간 발주 정보 수집 단일 채널.

### B. BPO 일체형 함의 (위즈돔·씨엘모빌리티)

**BPO (Business Process Outsourcing) 일체형** = 시스템(SaaS) + 차량·기사 운수 + 관제·CS·민원 응대까지 한 회사가 통째로 운영하는 패키지. 발주처는 시스템사 한 곳에만 통합 비용 지불.

**위즈돔·씨엘모빌리티가 BPO 일체형인 이유**:
- 위즈돔: 코모협동조합(운수) + 법무(태평양) + 회계(신우) 결합으로 풀스택 제공
- 씨엘모빌리티: 헬로버스·mobble + 운수사 매칭 + 관제 서비스 통합

**모빌리전트 참고 필요 사안**:
1. **SaaS 단가 비공개로 인한 가격 비교 불가** — BPO 일체형은 통합 청구라 SaaS 단독 단가가 노출되지 않음. 모빌리전트는 운수사 직접 SaaS 영업 시 **위즈돔·씨엘 BPO와는 다른 카테고리(시스템사 직판)** 에서 경쟁 → 가격 비교 대상은 UNIBUS·유모스원 같은 분리 SaaS 모델
2. **BPO의 발주처 락인 효과** — 시스템 교체가 운수사 교체까지 동반하므로 발주처는 한 번 도입하면 쉽게 못 바꿈. 위즈돔 176사·씨엘 354사 자가신고 고객사는 진입 난도 매우 높음
3. **운수사 OEM 영업이 유효한 이유** — 발주처(BPO 락인) 대신 **낙찰 운수사에 SaaS만 분리 영업** 하면 BPO 락인 효과 우회 가능
4. **모빌리전트가 BPO 일체형으로 전환할 옵션** — (주)대원관광 등 운수사 결합으로 풀스택 제공 시 위즈돔·씨엘과 같은 카테고리 진입 가능. 단 운수업 결합 없이 SaaS만으로는 BPO 일체형 진입 불가

# 4부. 시스템 사용 패턴 분석

## 4-1. 발주 공고의 시스템 사양 명시 빈도

본 보고서가 표본 확인한 범위에서 **시스템 단독 분리발주는 매우 드물고**(경기도청 본청·경기도교육청 북부청사·서울특별시 초등 스쿨버스·국립목포대 정도), **차량/기사 운행용역 공고에 시스템 사양이 평가조건·특수조건으로 포함된 경우도 소수**(LH 서울본부·분당서울대병원·셀트리온 2025 안내문 등). 다수 공고는 시스템 사양 미명시이며 운수사 자율 도입이 일반적.

## 4-1-A. 실제 수요 구조 — 공고에 안 보이는 시스템 시장

공고에 시스템 사양이 명시되지 않아도 도입은 발생. 결정 주체 분류:

| 결정 주체 | 동기 | 모빌리전트 진입점 |
|---------|---------|------------------|
| 발주처 | 분리발주(경기도청·경기도교육청·서울시) 또는 사양 명시(LH 서울본부·분당서울대병원) | 직접 입찰 — 확산성 미검증 |
| 발주처 GP팀 별도 RFP | 운수사 입찰과 분리된 본사 RFP | 본사 영업 (Track 2) |
| 운수사 (낙찰 후 자체 도입) | 품질평가 가산점·운영 효율·DTG 법정 의무·후속 입찰 신인도 | **운수사 직접 영업 (대규모 미개척 채널)** |
| 산단협의체 / 입주기업 협회 | 단지 단위 공동 통근 | 산단별 영업 |

→ 공고를 기다리는 영업보다 **운수사 직접 영업 + 발주처 GP팀 직접 제안 + 신규 채널 모니터링** 병행이 효율적.

## 4-2. 발주 채널 — 다양한 채널 나열

| 순위 | 타깃 | 진입 형태 | 근거 |

| **1** | **시스템 단독 분리발주가 발생하는 발주처 (유형 한정 X)** | 직접 입찰 (수의계약 활용 포함) | 검증 사례: 경기도청 본청(에스원 2026 낙찰)·경기도교육청 북부청사(유모스원)·서울특별시 초등 스쿨버스(UNIBUS)·국립목포대(UNIBUS). 추가 유형 발견 시 즉시 응모. 채널 모니터링 자동화로 누락 방지 |

## 5-2-A. 핵심 전략 — KD 운수사 역량 확보를 통한 풀스택 경쟁력 (사용자 강조)

**시장 진단**:
- 시스템 단독 분리발주 시장은 광역지자체 3건(경기도청 본청·경기도교육청 북부청사·서울특별시) 검증 — **경기도청은 에스원에게 넘어감(삼성그룹 시스템 광역지자체 진출 신호)** + 17개 시도/시도교육청 확산성 추가 검증 채널
- 발주 공고의 90%+는 시스템 사양 미명시 → 시스템사 단독 진입 어려움
- **위즈돔이 시장 1위인 이유 = 코모협동조합으로 운수사 역량 결합한 풀스택 모델**
- 헬로버스도 운수까지 묶은 번들 위탁운영으로 354사 확보

**모빌리전트의 경쟁 조건**:
- **모빌리전트(시스템) + KD/대원관광(운수사 역량) = 풀스택 패키지 입찰 능력 = 위즈돔과 대등한 경쟁력**
- 시스템 SaaS 단독으로는 위즈돔·헬로버스 대비 영업 능력·운영 역량 부족 (지원 인프라·운수사 네트워크·법무·회계 부재)
- **카모마일 + 대원관광 결합은 모빌리전트가 시장 진입을 위한 최소 필수 조건**

**SK하이닉스 입찰 잠재 첫 시도 — 현 상황 + 경쟁 환경**:
- **현재 상태**: 모빌리전트-KD 카모마일 도입 **계약 협상 진행 중** (체결 전). SK하이닉스 통근버스 **공고 미게시** — KD 응모 예정. **수주된 사례 아님**
- ⚠ **현 점유자 위즈돔(HAPPYROAD)** — `commute-h.e-bus.co.kr/client/skhynix` 시스템 + 이천 현장 위즈돔 정규직(기획·관제·CS·VOC 다수) + 활기찬중부관광 등 전세버스사 노선 분담의 **2단 구조 다년 위탁** 운영 중
- **KD 응모 시 경쟁 시나리오**:
  - 신규 노선·확장 입찰 가능성 (위즈돔 운영과 병행)
  - 기존 다년 위탁 만료 후 재발주 가능성 (위즈돔이 갱신 우선권 보유)
  - 부분 노선 분리발주 가능성
- 협상·공고·응모·수주·운영 모두 단계별 성공해야 첫 실증 사례 성립
- **성공 시 기대 효과**: (1) 위즈돔 점유 시장 첫 진입 / (2) SK그룹 레퍼런스 일부 확보 (현 위즈돔 점유) / (3) 후속 대기업 통근버스 입찰 확장 기반
- **실패 시 영업 대안**: KD 운수사 역량으로 다른 대기업(헬로버스·UNIBUS 미점유) 입찰 응모 — 위즈돔 미점유 화이트스페이스 우선 공략

## 5-3. 2-Track 영업 전략 (민간)

LG디스플레이 사례로 확정된 표준:

```
Track 1 (운수사 OEM 영업)
   조합 EDM 모니터링 → 낙찰 운수사 명단 확보 → 사후 시스템 번들 영업
   
Track 2 (본사 GP팀 RFP 별도)
   발주처 본사(LG디스플레이 Global GP팀 등) 직접 접촉 → 운수사와 분리된 시스템 SaaS 도입 제안
```

**Track 2 메시지**: "운수사 교체와 무관하게 시스템 유지·확장 가능" — 본사 GP팀 입장에서 multi-year 시스템 안정성 가치 강조

## 5-4. SaaS·단말기 가격 포지셔닝 (운수사 영업)

3-3 가격 비교 매트릭스 기반 영업 권고. **상세 단가 비교는 3-3 참조**.

### 권장 가격 구간
- **단말기 포함 풀패키지**: 차량당 월 **5~7만원** (모델 B 또는 C 기준)
- **단말기 매입 분리 시**: 초기 35만원/대 + 월 4~6만원/대 (모델 A 기준)
- 위치: UNIBUS 6.2만원/대/월(학교 모델, 단말기 일체) + 유모스원 4.5만원/대/월(시스템+운영비) 동급. 위즈돔·씨엘 BPO 일체형보다 SaaS 단가 명확히 분리 제시

### 단말기 공급 모델 권고
- **(B) 단말기 무상 + 36개월 약정 + 위약금** 또는 **(C) 단말기 임대 분리(1만원/대/월) + SaaS 별도(3~5만원/대/월)**
- (A) 단말기 매입형은 운수사 초기 자본 부담 큼 → 영업 진입 어려움

### BPO 락인 우회 영업 전략
