## 📌 경영진 요약 (Executive Summary)

### 시장 한 줄 요약
한국 공공 통근버스 발주의 90%+는 "차량+기사 번들 임차"이고 모빌리전트(시스템사)는 4중 진입 장벽으로 직접 입찰이 불가능하다. 시스템 단독 분리발주는 경기도청 본청 1건만 검증됐고, 민간 발주는 전세버스조합 EDM 채널을 통해 사양에 시스템 요구가 거의 없어 운수사가 자율 도입한다. 시장 규모는 민간이 압도적이며 (헬로버스 354사 + 위즈돔 176사), 위즈돔은 "협동조합 + SaaS" 결합 모델로 가장 강력한 경쟁자다.

### 모빌리전트 핵심 전략 3가지
1. **공공 분리발주 트랙 직접 입찰** — 경기도청 본청·LH 서울본부·17개 시도청 모니터링 (시스템 사양 명시 발주처만 선별)
2. **운수사 OEM 채널 + 그룹사 면허 우회** — 노바/카모마일(KD) 또는 KD운송그룹 (주)대원관광 등 면허 보유 파트너와 결합해 풀스택 입찰
3. **민간 B2B SaaS 화이트스페이스 영업** — 헬로버스 354사·위즈돔 176사 외 중견기업·산단·대학·병원

### 향후 3개월 최우선 액션 Top 5 (KD-SK하이닉스 영업 활성화 반영)
> **사실 확정** (사용자 1차 정보):
> - (주)대원관광 = KD운송그룹 계열사 + **서울특별시전세버스운송사업조합 회원** + 전세버스 면허 보유
> - **카모마일(Camomile) = 모빌리전트의 버스운행관리시스템 제품명**
> - **모빌리전트-KD 카모마일 도입 계약 협상 진행 중** (체결 전, 아직 미완결)

1. **KD-카모마일 계약 협상 우선 완결** → 협상이 완결되어야 후속 SK하이닉스 입찰 응모 시 카모마일 시스템 공급 가능. 위즈돔-코모협동조합 모델과 정면 경쟁할 풀스택 패키지 구조 첫 시도

# 1부. 시장 구조 분석

## 1-1. 시장의 양분 구조

한국 통근버스 공공 발주는 **2가지 유형**으로 명확히 양분된다:

| 유형 | 정의 | 비중 | 모빌리전트 진입 |
|------|------|------|----------------|
| **① 시스템 단독 분리발주** | 운행관리시스템(단말기·앱·웹) 임차용역만 별도 발주 | 매우 희소 (검증 1건) | ✅ 직접 입찰 가능 |
| **② 차량+기사 번들 임차/위탁** | 차량·기사·운영을 통합한 전세버스 임차 | 공공 발주의 90%+ | ❌ 시스템사 단독 불가 (전세버스 면허 필수) |

**검증된 유일한 시스템 단독 분리발주처**: 경기도청 본청 (제2026-454/493/517호, 추정 0.89억/36개월/55대)

**민간 발주**: 거의 대부분 ② 유형이며 시스템 사양 명시 없음 → 시스템 도입 결정은 운수사 자율 또는 발주처 본사 GP팀 별도 RFP

## 1-2. 4중 진입 장벽 (공공 시장)

| 장벽 | 근거 법령/제도 |
|------|--------------|
| ① 전세버스 운송사업 등록 | 「여객자동차운수사업법」 제4조 (업종코드 5805) |
| ② 직접생산확인증명서 | 중소기업제품 구매촉진법 제9조 (공공기관통근운송서비스 코드 7811189901, 중기부 고시 제2024-100호) |
| ③ 자기명의 등록 차량 + 45인승 이상 운행실적 | 공고 명시 |
| ④ **공동계약(컨소시엄) 불허 + 하도급 금지** | 공고 명시 — 시스템사+운수사 컨소시엄 가설 봉쇄 |

→ **모빌리전트가 시스템만 가진 상태로 공공 차량+시스템 번들 시장 진입은 구조적으로 불가능.** 진입하려면 (a) 그룹사 면허 활용, (b) 전세버스 자회사 신설, (c) 기존 운수사 인수 중 선택.

**직접생산확인 절차** (중기부 판로정책과 소관, 4단계):
1. 공공구매종합정보망(SMPP) 접속 + 회원가입 + 기업·공장·제품 등록
2. 온라인 자료제출 및 신청서 제출
3. 한국중소벤처기업유통원 방문 실사
4. 직접생산기업 확인서 발급

선행 요건: **전세버스 면허 + 직영차량 보유**가 모두 충족되어야 신청 가능.

## 1-3. 발주 채널 구조

### 공공 채널
```
[발주처]
    ↓
[나라장터(g2b.go.kr) 또는 LH e-bid(ebid.lh.or.kr) 또는 자체 게시판]
    ↓
[전세버스 운수사 응모 — 4중 장벽 충족 필수]
    ↓ 낙찰 후 시스템 조달 (3가지 경로)
    ├── (a) 운수사 자체 보유 시스템 (다수)
    ├── (b) 시스템사 OEM 공급 (← 모빌리전트 진입점)
    └── (c) 시스템 미사용 수기 운영 (정부서울청사 17개사 사례)
```

### 민간 채널 — 서울특별시전세버스운송사업조합 EDM
```
[발주 기업 본사 GP팀]
    ↓ 운행사 선정 공문
[서울특별시전세버스운송사업조합(+경기도 조합 동시)]
    ↓ 전회원사 일괄 EDM 발송
[조합 회원사 응모 — 자차 70% + 신용 B- 이상]
    ↓
[OT설명회 → 본사 직접 평가(품질 60% + 가격 40%)]
    ↓ 낙찰 (3년 또는 3+2년 계약)
[낙찰 운수사 — 시스템은 운수사 자율 또는 본사 별도 RFP]
```

**공통 채널 확정 사례 (조합 EDM 통과)**:
- 민간: LG디스플레이 4건(2023.02·07.05·07.26 외), 셀트리온(2023.09.11)
- 공공: 국회사무처(2022.12.22), 정부서울청사(2023.10.31)

**핵심 시사점**: tourbus.or.kr 모니터링이 모빌리전트의 민간 발주 정보 수집 단일 채널.

# 3-A부. 사업 유형별 시나리오 비교 (B2G·B2B·B2C)

같은 "버스 운행관리시스템"이라도 사업 유형에 따라 발주 구조·승객 흐름·시스템 기능 구성이 본질적으로 다르다. 모빌리전트(카모마일)는 어떤 시나리오를 타깃하느냐에 따라 진입 전략이 달라진다.

## 3-A-1. B2G 시나리오 — 광역버스 좌석예약 (위즈돔 MiRi 검증 사례)

**거버넌스 3자 분담**:
| 주체 | 역할 |
|------|------|
| 위즈돔 (플랫폼 운영) | 예약 앱·결제·예치금 관리 |
| 지자체·국토부 (정책) | 노선·요금·한정면허 부여 |
| 운수사 (실 운행) | 차량·기사·운행·분실물 처리 |

**승객 표준 흐름** (검증됨, 사용자 가설 정확 일치):
```
① 앱 설치 → ② 교통카드 등록 → ③ 예치금 충전 → ④ 노선 검색·예약 (운행일 7일 전 10시 오픈) → ⑤ 운행일 출발 1시간 전까지 변경 가능 → ⑥ 탑승 시 등록 교통카드 태깅 → ⑦ 예약 확인 자동 처리
```

**노선 등급별 요금** (MiRi 1차 자료):
- M버스 (광역급행) 예치금 2,800/3,200원
- G버스 (광역) 동일 2,800/3,200원
- P버스 (프리미엄) 3,050/3,450원
- 30km 초과 거리비례제·환승할인·청소년할인 등 일반 대중교통 요금체계

**모빌리전트 진입성**: B2G 광역버스는 지자체+국토부+운수사 3자 거버넌스라 진입 장벽 매우 높음. 위즈돔 외 신규 진입 사례 없음.

## 3-A-2. B2B 시나리오 — 민간 기업 통근버스 (LG디스플레이 검증 사례)

**발주~계약 표준 흐름** (LG디스플레이 PDF 원문 검증):
```
① 발주처 GP팀(예: LG디스플레이 Global GP팀) 1차 EDM 작성
② 지역 전세버스조합(서울 tourbus.or.kr 등)에 공문 발송
③ 조합 → 전회원사 일괄 EDM 배포
④ 회원사 응모 (자차 70%·차량 9년 이내·신용 B 이상)
⑤ 발주처 1차 이메일 회신 마감 (예: 2023.08.04)
⑥ OT 설명회 (품질 60% + 가격 40% 평가 세부 지표 공개)
⑦ 종합평가 → 낙찰
⑧ 운수사가 시스템 자율 도입 (사양 명시 없음)
```

**승객(직원) 사용 흐름** (헬로버스·위즈돔 AIBOS·UNIBUS 공통):
```
① 사원증 등록 (또는 QR·앱) → ② 앱에서 노선·시간 확인 → ③ (옵션) 좌석 예약 → ④ 탑승 시 사원증/QR 인증 → ⑤ 관리자 웹에서 운영자 통계 확인
```

**핵심 발견 — LG디스플레이 EDM PDF 원문 grep 결과 (12차 검증)**:
- "시스템·GPS·앱·QR·RFID·예약·인증·DTG·관제·위치·결제·소프트웨어·플랫폼·모바일·디지털·IT" 키워드 매칭 **0건**
- 자격 요건은 운행 인프라(차량·신용·자차 비율)만
- 품질 60% 평가 세부 지표는 OT 설명회에서만 공개

→ **사용자의 "공고에 시스템 명시 없다" 관찰이 1차 자료로 입증.**

## 3-A-3. B2C 시나리오 — 이벤트·여행 셔틀 (콘서트·테마파크·리조트)

**12차에서 검증된 클레임 없음** — 셔틀콕·전세버스 매칭 플랫폼 사례는 후속 조사 필요.

**일반 추정 흐름** (검증 필요):
- 발주: 콘서트 주최·테마파크 운영사 → 이벤트성 단발 발주 → 전세버스 매칭 플랫폼(셔틀콕 등) 활용
- 승객(일반인): 앱·웹에서 좌석 예약 → 신용카드·간편결제 → QR/탑승권 인증
- 시스템 수준: 단순 위치추적·일회성이 다수, 풀스택은 드묾

# 4부. 시스템 사용 패턴 분석

## 4-1. 발주 공고의 시스템 사양 명시 비율 (검증 표본 기준)

공공 발주 9건 검증 결과:
- ✅ **명시: 2건 (22%)** — 경기도청 본청(분리발주), LH 서울본부(차량 사양 일부)
- ❌ **미명시: 6건 (67%)** — 경기도 북부·인천공항보안·LH 본사(진주)·행안부·KIGAM·군산산단
- ⚠ **확인 불가: 1건 (11%)** — 서울지방항공청

LH 5년치 45건 중 표본 4건 (서울·대전충남·본사·인천) 추가 검증 결과 동일 패턴 — **서울본부만 사양 명시**.

민간 5건 (LG디스플레이 4건 + 셀트리온 1건) 모두 **시스템 사양 미명시**. **LG디스플레이 EDM PDF 원문 grep** 결과 "시스템·GPS·앱·QR·RFID·예약·인증·DTG·관제·위치·결제·소프트웨어·플랫폼·모바일·디지털·IT" 키워드 **0건**.

## 4-1-A. 실제 수요 구조 — 공고에 안 보이는 시스템 시장은 어떻게 존재하는가? (12차 핵심 분석)

사용자 핵심 질문: "공고에 시스템 명시가 거의 없는데 실제 수요가 어떻게 존재하는가?"

**답**: 공고에 명시되지 않아도 시스템 도입은 발생함. 결정 주체와 동기 분석:

| 결정 주체 | 도입 동기 | 발생 빈도 추정 | 모빌리전트 영업 진입점 |
|---------|---------|--------------|------------------|
| **발주처** | 시스템 분리발주 (경기도청 본청 모델) 또는 사양에 시스템 탑재 명시 (LH 서울본부) | **희소** (검증 2건만) | 직접 입찰 (1순위 트랙) |
| **발주처 GP팀 별도 RFP** | 운수사 입찰과 분리된 본사 시스템 RFP | 빈도 미상 (LG디스플레이 가능성 추정) | 본사 영업 (Track 2) |
| **운수사 (낙찰 후 자체 도입)** | (a) 발주처 품질평가 60% 가산점 / (b) 운영 효율 (배차·기사관리·민원) / (c) DTG 법정 의무 대응 / (d) 후속 입찰 신인도 누적 | **다수 추정** (대부분의 공고에서 시스템 미명시이지만 운수사가 자체 도입) | **운수사 직접 영업 (가장 큰 미개척 채널)** |
| **산단협의체 / 입주기업 협회** | 단지 단위 공동 통근 시스템 (군산국가산단 사례) | 산단별 1건 수준 | 산단별 영업 |

→ **모빌리전트 카모마일 영업 진입점 핵심 시사**: 발주 공고에 시스템 사양이 명시되기를 기다리는 영업 전략은 비효율. **(a) 운수사 직접 영업** + **(b) 발주처 GP팀에 "품질평가 60% 가산점" 메시지로 RFP 별도 트랙 제안**이 핵심.

## 4-2. 시스템 사용 시나리오 3가지

발주처가 시스템 사양을 명시하지 않더라도, 실제 운행은 다음 3가지 패턴으로 나뉜다:

| 패턴 | 설명 | 검증 사례 |
|------|------|---------|
| (a) **풀스택 시스템** | 인증·예약·관제·앱 + RFID/QR 사양 명시 | **경기도청 본청 2026** (운행관리시스템 임차용역 분리발주) |
| (b) **단순 위치추적** | "버스운행정보제공시스템 탑재 차량" 등 차량 사양 항목 | **LH 서울본부 2025** (2501353-00) |
| (c) **시스템 미사용** | 차량 9년 이내·자차 70%·신용 B 이상 등 운수사 기본 자격만 | **LG디스플레이 파주 4건·셀트리온·KIGAM·행안부·정부서울청사·LH 11개 부서** |

**모빌리전트 영업 함의**: (c) 패턴이 다수 → 발주처가 시스템 도입의 비용 절감·관리 효율 가치를 인식하지 못한 상태. **시스템 도입의 가치를 발주처에 설득하는 것이 핵심 영업 메시지**.

- 모빌리전트 영업 함의: tourbus.or.kr 공고 모니터링 + **운수사 직접 영업 + 발주처 본사 GP팀 직접 접촉**의 3-Track 병행이 정답

## 5-2-A. 핵심 전략 — KD 운수사 역량 확보를 통한 풀스택 경쟁력 (사용자 강조)

**시장 진단**:
- 시스템 단독 분리발주 시장은 매우 희소 (경기도청 본청 1건)
- 발주 공고의 90%+는 시스템 사양 미명시 → 시스템사 단독 진입 어려움
- **위즈돔이 시장 1위인 이유 = 코모협동조합으로 운수사 역량 결합한 풀스택 모델**
- 헬로버스도 운수까지 묶은 번들 위탁운영으로 354사 확보

**모빌리전트의 경쟁 조건**:
- **모빌리전트(시스템) + KD/대원관광(운수사 역량) = 풀스택 패키지 입찰 능력 = 위즈돔과 대등한 경쟁력**
- 시스템 SaaS 단독으로는 위즈돔·헬로버스 대비 영업 능력·운영 역량 부족 (지원 인프라·운수사 네트워크·법무·회계 부재)
- **카모마일 + 대원관광 결합은 모빌리전트가 시장 진입을 위한 최소 필수 조건**

**SK하이닉스 입찰 잠재 첫 시도**:
- **현재 상태**: 모빌리전트-KD 카모마일 도입 **계약 협상 진행 중** (체결 전). SK하이닉스 통근버스 **공고 미게시** — KD 응모 예정. **수주된 사례 아님**
- 협상·응모·수주 모두 성공해야 첫 실증 사례 성립
- **성공 시 기대 효과**: (1) 풀스택 모델 첫 실증 / (2) SK그룹 레퍼런스 확보 (현재 SK그룹은 위즈돔 점유) / (3) 후속 대기업 통근버스 입찰 확장 기반
