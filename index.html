2. 시스템사 계약 구조 매트릭스

시스템사 운영사 민간 본사 직접 운수사 경유 (OEM) 컨소시엄 공공 직접 입찰
헬로버스 CIEL Mobility ✅ 주력 (HR/총무팀) + 번들 위탁운영 △ 미확인 ❌ 공동계약 불허 ❌ 흔적 부재
UNIBUS ㈜썬더디에스 ✅ 기업/대학/산단 직접 △ 미확인 ❌ 불허 △ KICOX 사례 1건 — 계약 구조 미규명
셔틀아이디 ㈜스쿨버스 ✅ Freemium B2B SaaS △ 미확인 ❌ 불허 ❌ G2B 흔적 부재
HMG autobus 현대엔지니어링/오토에버 — (사내 전용) — — —
카카오모빌리티 통근셔틀 카카오모빌리티 ✅ B2B (모바일 QR+사전예약) 미상 ❌ 불허 미확인

핵심 관찰:

  • 가설 3(컨소시엄 입찰) → 법적으로 폐기 (공동계약 불허 + 직접생산확인 + 하도급 금지 3중 봉쇄)
  • 가설 1(민간 B2B SaaS 직접) → 확정 — 3사 모두 주력 모델
  • 가설 2(운수사 경유 OEM) → 부분 지지 — LH 공고가 "버스운행정보제공시스템 탑재 차량"을 요구하므로 운수사가 시스템을 어딘가에서 조달 중. 시스템사로부터 OEM 받는지 자체 개발인지는 미확인

3. 차량+시스템 번들 공고의 시스템 조달 메커니즘

[공공 발주처]
    ↓ (차량+기사+운영 번들 임차/위탁용역)
[전세버스 운수사 — 면허·직접생산확인 보유]  ← 시스템사 단독 또는 컨소시엄 진입 모두 불가
    ↓ 시스템 조달 (3가지 경로)
    ├── (a) 자체 개발/내부 보유 시스템 (비중 추정 다수)
    ├── (b) 시스템사 OEM/하청 공급 (모빌리전트의 잠재 진입점)
    └── (c) 시스템 미사용, 수기 운영 (정부서울청사 17개사 사례)

모빌리전트의 (b) 진입 가능성: 운수사에 시스템을 OEM 공급. 단 운수사가 시스템 사양 요구를 직접 받지 않는 한 동기 부족. LH 공고처럼 사양에 "시스템 탑재" 요구가 명시될 때만 외주 수요 발생.

4. 발주 패턴 분석 (12건 표본)

  • 계약형태: 공공의 90%+가 차량+기사 번들. 검증된 시스템 단독 분리는 경기도청 본청 1건 (KICOX는 계약 구조 미규명)
  • 계약기간: 단기 11개월 ~ 다년 48개월
  • 단가 스펙트럼: 1대 3,072만원/11개월(인재개발원) ~ 38.4억/4년(인천공항). 시스템 임차 단독은 차량당 약 45,000원/대·월 (경기도청 기준)
  • 자격 제한: 4중 장벽 — 시스템 단독 사업자 컨소시엄 입찰까지 모두 불가
  • 반복 발주: 다년계약 만료 시점이 유일한 신규사업자 진입 창구

5. 영업 타깃 — 누구에게, 어떻게

우선순위 1: 광역지자체 본·분청사 시스템 단독 분리발주

  • 누구: 17개 시도청 자산관리과/총무과 차량지원팀
  • 메시지: "경기도 모델" 레퍼런스 — 차량 운수사는 운수사 그대로 두고, 시스템만 IT 사업자가 임차 공급하는 분리 구조
  • 검증 필요: 17개 중 다른 지자체에 분리발주 선례 추가 존재 여부. 정부서울청사는 분리발주 아닌 단순 임차 구조 확인 — 경기도 모델은 예외적 가능성 高
  • 채널: 나라장터 알리미 + 직접 방문 영업

우선순위 2: 공공 번들 낙찰 운수사 OEM 영업

  • 누구: LH·인천공항보안·서울지방항공청·정부서울청사 등 차량 임차 발주를 수주하는 전세버스 사업자 (특히 LH형 시스템 사양 명시 공고 수주 운수사)
  • 메시지: 사양 충족용 시스템 부속 납품 (운수사가 입찰 사양에 IoT/앱 요건 충족하기 위해 외주)
  • 채널: 발주공고 모니터링 → 낙찰사 추적 → 직접 영업
  • 경쟁: 헬로버스·UNIBUS·셔틀아이디와 정면 경쟁

우선순위 3: 민간 대기업·중견기업 B2B SaaS

  • 누구: 헬로버스 354사 외 화이트스페이스 (중견 대기업, 중견 제조사, 신규 산단 입주기업)
  • 메시지: 셔클 운영 노하우 + RFID 직접 개발 가격경쟁력
  • 차별화: 헬로버스 번들 위탁운영과 차별화하려면 "시스템 only + 운수사 자율선택" 포지션 명확화

우선순위 4: 산업단지관리공단·KICOX·산단 협의체 (가설 단계)

  • 누구: 한국산업단지공단(KICOX) 본부 + 산단 입주기업 협의체 (군산·시화·반월·창원·울산·여수·구미·온산 등)
  • 현재 근거 약함: UNIBUS가 KICOX 통근버스시스템에 포함되어 있다는 공지 1건만 확인. 계약 구조(직접/OEM/협의체) 미규명. (b)/(d) 시나리오면 본 우선순위는 우선순위 2(운수사 OEM)로 통합·강등
  • 선결 과제: KICOX 입찰공고·산단 협의체 자료 직접 확인으로 계약 구조 규명
  • 메시지 (직접 계약 시나리오 확인 시): UNIBUS 대체/보완 솔루션, 산단별 RFID+앱+웹 분리발주

우선순위 5: 대학·병원·종교기관·리조트

  • 누구: UNIBUS·CIEL 미도입 대학, 대형병원, 리조트 (한화 리조트 등)
  • 진입 포인트: 캠퍼스 셔틀 + 직원 통근 통합 솔루션 PoC

헬로버스 CIEL Mobility 354개 기업 (삼성·현대차·쿠팡·POSCO·LG화학·SK·CJ·한화·농심·현대백화점·넥센·현대모비스 등) 시스템 SaaS + 번들 위탁운영 통합 (운수까지 포함) QR + 사원증/출입카드
UNIBUS ㈜썬더디에스 기업/산단/대학/중고/유치원 4세그먼트 + KICOX(공공) 시스템 + 차량단말기 + 컨설팅 패키지 RFID + 사원증·학생증 + 신용카드·가상계좌·휴대폰 소액결제 통합
셔틀아이디 ㈜스쿨버스 기업통근·산단셔틀·전세버스 Freemium SaaS (1계정 200명 영구 무료, Lite/Standard/Enterprise) 미확인
HMG autobus 현대엔지니어링/오토에버 HMG 계열사 30~50개 in-house 사내 전용, 외부 비공개 사내 전용
카카오모빌리티 통근셔틀 ⭐ 신규 카카오모빌리티 B2B 기업 통근셔틀 모바일 QR + 사전예약 (iOS id6478443360 / Android com.scoop.mobiliteasykakaoshuttle) 모바일 중심 — RFID 단말과 차별화

모빌리전트 포지셔닝 제언:

  • vs CIEL: 시스템 only + 운수사 자율 선택 (CIEL은 번들 운영을 함께 묶음 → 운수사를 이미 정한 발주처는 CIEL 부적합)
  • vs UNIBUS: 동급 기능, 가격 또는 셔클 운영 신뢰도로 차별화. 결제 모듈 부재가 기능 갭 → 공공·산단 RFP에 결제 요건 포함 시 PG 연계 또는 자체 개발 필요
  • vs 셔틀아이디: 엔터프라이즈/공공 사양 충족(CSAP·CIS 등), Freemium보다 안정성/보안 강조
  • vs 카카오모빌리티: 모바일 QR 대비 RFID의 가치(보안·사원증 활용·앱 미설치 사용자 지원) 명확화

7. 공공 시장 진입 경로 (4중 장벽 우회)

옵션 내용 시간·비용 우선도
(a) 신규 전세버스 자회사 설립 여객자동차운수사업법 제4조 등록 + 직영차량·차고지 확보 + 직접생산확인 신청 1년+ 추정, 수십억 자본 필요 (구체 미규명) 낮음
(b) 기존 운수사 인수 50대 규모 전세버스 운수사 M&A 가격대 미규명 중간
(c) 노바/카모마일(KD) 그룹사 면허 활용 그룹사가 면허 보유 시 우회 가능 사내 확인 필요. 최단 경로 후보 높음

직접생산확인 4단계 절차 (중기부 판로정책과 소관):

  1. 공공구매종합정보망(SMPP) 접속 + 회원가입 + 기업·공장·제품 정보 등록
  2. 온라인 자료제출 및 신청서 제출
  3. 한국중소벤처기업유통원 방문 실사
  4. 직접생산기업 확인서 발급

선행 요건: SMPP 회원가입 + 전세버스 면허 + 직영차량 보유가 모두 충족되어야 신청 가능. 법적 근거: 중소기업제품 구매촉진 및 판로지원에 관한 법률 제9조. 품목 기준: SMPP 973개 품목 (중기부 고시 제2024-100호, 2024.11.29 시행), 공공기관통근운송서비스(7811189901) 포함.
